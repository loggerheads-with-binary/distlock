Protobuf wire types for [distlock](https://github.com/loggerheads-with-binary/distlock), a distributed
lock service. The `.proto` file is compiled at build time with `protox`, so you do not need `protoc`.

You only need this crate to speak the protocol directly. For normal use, depend on
[`distlock-client`](https://crates.io/crates/distlock-client) instead.

```toml
[dependencies]
distlock-proto = "0.2"
```

The messages are generated by [`prost`](https://crates.io/crates/prost). The schema is
[`proto/distlock/v1/distlock.proto`](https://github.com/loggerheads-with-binary/distlock/blob/main/crates/distlock-proto/proto/distlock/v1/distlock.proto).
